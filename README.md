

**Project Status:** Code Complete  | Frontend Only | Not Deployed

## Deployment Note
This project is intentionally not deployed. Spotify's Web API requires server-side authentication and secure handling of API keys, which cannot be implemented safely in a frontend-only application hosted on GitHub Pages. 

This showcases UI/UX and frontend skills only. For full-stack implementation, a Node.js backend would be required.

##  Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript ES6+
- **Layout:** Flexbox, CSS Grid, Media Queries
- **Concepts:** DOM Manipulation, Event Handling, Component-based Structure
- **Tools:** VS Code, Git, GitHub

##  Features
- Fully responsive design - works on mobile, tablet, desktop
- Replicated Spotify's web player UI including sidebar, navbar, and music cards
- Interactive player controls: play, pause, next, previous, volume
- Dynamic playlist rendering using JavaScript and local JSON data
- Hover effects and micro-interactions matching original UX



##  What I Learned
- Building complex, responsive layouts with modern CSS
- Translating design mockups into pixel-perfect code
- Managing UI state with vanilla JavaScript
- Understanding limitations of frontend-only apps vs full-stack architecture

## Run Locally
1. Clone the repo
2. Open `index.html` in browser
3. No dependencies required
